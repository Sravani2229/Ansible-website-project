# Ansible Website Deployment

## Project Description

This project demonstrates automated website deployment using
Ansible on an AWS EC2 Ubuntu server.

## Technologies

- AWS EC2
- Ubuntu
- Ansible
- Nginx
- Git
- GitHub
- HTML

## Workflow

VS Code
→ GitHub
→ Ubuntu
→ Ansible
→ AWS EC2
→ Nginx
→ Website

## Deployment

Run:

ansible-playbook -i inventory deploy.yml
